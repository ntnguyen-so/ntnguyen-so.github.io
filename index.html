AdapAD

The repository includes expert-labelled data, benchmark results, validation experiments, and replication instructions. My PhD work also integrated AdapAD into the Azure-hosted Smart Ocean platform.

02 / INTERPRETABLE MACHINE LEARNING

MuMSAD

Find the anomaly.
Help explain what went wrong.

An interpretable AutoML framework that selects among 10 multivariate anomaly detectors, supporting marine data-quality control and root-cause analysis.

Applications include identifying malfunctioning sensors. The repository provides deep-learning and feature-based selectors, benchmark tooling, and reproducibility guides.

03 / FULL-STACK MULTI-AGENT DEMO

Subsea Lens

From pressure alerts
to an inspection decision.

Three agents assess sensor quality, investigate possible causes, and assemble an operator report. An additional review checks the report against its sources.

A full-stack dashboard connects a simulated 11.2 km pipeline network, 112 pressure instruments, evidence references, and replayable evaluations. Saved evaluation playback needs no Copilot account.

04 / GOVERNED AI WORKFLOW

Inspection Finding Triage

The model proposes.
The engineer approves.

A Python workflow that turns 21 offshore inspection findings and an equipment registry into structured draft maintenance tickets.

Deterministic checks validate evidence and coverage, calculate urgency, and apply review rules. The complete batch is written only when every finding has a valid ticket; otherwise the previous output stays unchanged.
